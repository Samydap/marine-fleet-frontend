# Imágenes del Centro de Comando

El tablero (`/comando`) usa las imágenes que encuentre en esta carpeta. Si falta
alguna, muestra una silueta en su lugar, así que se pueden ir agregando de a una.

Formatos: `.webp`, `.png`, `.jpg`, `.jpeg` o `.avif`. El nombre del archivo es lo
que cuenta (en minúsculas, sin espacios).

| Archivo         | Dónde se usa                 | Recomendado                     |
| --------------- | ---------------------------- | ------------------------------- |
| `luffy`         | Cartel de LUFFY              | Rostro, proporción 5:4, 400 px  |
| `buggy`         | Cartel de BUGGY              | Rostro, proporción 5:4, 400 px  |
| `crocodile`     | Cartel de CROCODILE          | Rostro, proporción 5:4, 400 px  |
| `doflamingo`    | Cartel de DOFLAMINGO         | Rostro, proporción 5:4, 400 px  |
| `kaido`         | Cartel de KAIDO              | Rostro, proporción 5:4, 400 px  |
| `barbanegra`    | Cartel de BARBANEGRA         | Rostro, proporción 5:4, 400 px  |
| `zoro`          | Cartel de ZORO               | Rostro, proporción 5:4, 400 px  |
| `law`           | Cartel de LAW                | Rostro, proporción 5:4, 400 px  |
| `shanks`        | Cartel de SHANKS             | Rostro, proporción 5:4, 400 px  |
| `akainu`        | Misión Buster Call           | Cuerpo entero, fondo negro, 2:3 |
| `magellan`      | Misión Impel Down Guard      | Cuerpo entero, fondo negro, 2:3 |
| `kizaru`        | Misión Sabaody Raid          | Cuerpo entero, fondo negro, 2:3 |
| `oficial`       | Avatar del perfil (cabecera) | Cuadrada, 120 px                |
| `den-den-mushi` | Panel del Den Den Mushi      | Fondo transparente, 300 px      |

Las tarjetas de misión acercan la cabeza y el torso del oficial y funden el fondo
negro con el panel, así que la figura debe ir centrada y con la cabeza arriba.
